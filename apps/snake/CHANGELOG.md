# Changelog — Snake

## 0.1.3
- Intents (CardputerOS 0.7.0 and later, docs/intents.md): snake.high_score, snake.sound.

## 0.1.2
- New vector launcher icon (CardputerOS 0.6.0 and later; 0.5.0 icons were bitmaps).

## 0.1.1
- Launcher icon (shown by CardputerOS 0.5.0 and later).

## [0.1.0]
- Tablero de 40×20 con HUD de puntos y récord.
- Flechas del teclado (`;` `.` `,` `/`) o WASD, con buffer de giros.
- La velocidad sube con cada comida (140 ms → 55 ms por paso).
- Pausa (`space`/`p`), sonido on/off (`m`). Récord y sonido se guardan en NVS.
