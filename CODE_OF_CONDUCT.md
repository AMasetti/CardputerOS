# Code of Conduct

Be kind and be useful. This project welcomes people of every background and experience level.

* Treat others with respect; disagree with ideas, not people.
* No harassment, discrimination, or personal attacks.
* Assume good faith, and ask before assuming bad.
* Keep discussion on topic and technical where possible.

Maintainers may edit or remove contributions that break these rules and may ban repeat offenders.
Report problems by opening a private security advisory or contacting the maintainer through their GitHub profile.
